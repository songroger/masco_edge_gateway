# 第三代太阳能控制器 (V1.00)

来源: `docs/mptt-modbus.pdf`

## 适用型号

- XTRA-N G3
- XTRA-N G3 BLE
- Tracer-AN G3
- Tracer-CPN系列

## 通讯参数

| 项目 | 值 |
|------|-----|
| 协议 | Modbus-RTU |
| 默认从站ID | 1 |
| 波特率 | 115200 |
| 数据位 | 8 |
| 校验位 | N |
| 停止位 | 1 |
| 地址格式 | hex |
| 32位数据 | L寄存器 + H寄存器（低字在前） |

## 协议解析示例（摘自原文档）

### 读取蓄电池电压 (FC 0x04, 地址 0x3108)

发送: `01 04 31 08 00 01 BE F4`

接收: `01 04 02 0A 25 7E 4B` → 0x0A25 = 2597 → **25.97 V** (÷100)

### 读取保持寄存器 (FC 0x03, 地址 0x9000 起 3 个)

发送: `01 03 90 00 00 03 28 CB`

接收: `01 03 06 00 00 00 C8 01 2C A0 C6`
- 0x9000 蓄电池类型 = 0x0000 (User)
- 0x9001 蓄电池容量 = 0x00C8 = 200 Ah
- 0x9002 温度补偿 = 0x012C = 300 (即 3.00, 控制器处理为 -3)

### 写负载控制模式 (FC 0x10, 地址 0x903D)

发送: `01 10 90 3D 00 01 02 00 02 B3 75` → 写入值 2 (光控+多时段)

### 写线圈恢复出厂 (FC 0x05, 地址 0x0013)

发送: `01 05 00 13 FF 00 7D FF`

### 32 位数据示例

实际值 3000、倍数 100 时: L(0x3002)=0x93E0, H(0x3003)=0x0004

### 有符号数示例

0x3022 读值 0xFFF9 → 最高位 1 为负 → (32768-32761)/10 = **-0.7 A**
